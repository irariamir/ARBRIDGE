# Contributing

Thanks for helping improve ARBRIDGE. Keep changes focused, typed, tested, and documented. All product-facing copy should be professional English. Do not add shadows; follow `DESIGN.md`.

1. Open an issue for substantial changes and agree on the scope first.
2. Install Node.js 22.13+ and run `npm install`.
3. Run `npm run typecheck` and `npm test` before opening a pull request.
4. Never include credentials, private files, or generated secrets.
5. Describe what was actually tested and list limitations.

Security issues should be reported privately; see `SECURITY.md`.
