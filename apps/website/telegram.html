ARBRIDGE Telegram Bot

Connect the Chrome extension to your private Telegram chat using a short-lived one-time code. Send public HTTPS document links from Chrome and receive validated files here.

Connect

  1. Press Start in your ARBRIDGE bot private chat.
  2. In the extension choose Connect Telegram and send the displayed /connect code.
  3. Enter the confirmation code returned by the bot into the extension.

Commands

  • /status — recent delivered files
  • /library — delivered-file list
  • /help — help

No subscription, payment, receipt, deposit channel, or reviewer group is required. Files are temporary transfer jobs, not a permanent ARBRIDGE cloud library.
