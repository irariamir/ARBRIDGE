The repository includes a grammY command scaffold for ARBRIDGE. It is not yet connected to a user library or browser account.

Current commands

The bot source recognizes /start and /help and explicitly reports that library, search, settings, account pairing, status, and deletion are not available yet. It does not store incoming documents.

Pairing and delivery are not implemented

The intended design uses Telegram numeric user IDs and short-lived, single-use pairing tokens. The prototype does not issue pairing tokens, persist a verified chat ID, or call sendDocument for captures. A bot also cannot start a private conversation until the user opens it.

Do not send private documents to a bot instance built from this prototype. No secure storage, document processing, or user deletion workflow is in place.

Bot startup requires a server-side TELEGRAM_BOT_TOKEN. Keep it private; never put it in extension code or publish it in a repository.
