Security

Security is a
product feature.

The current downloader includes baseline SSRF controls. They reduce obvious risk but do not make the prototype safe for public hosting.

Implemented in the prototype

  • HTTPS-only requests on the standard port; credentials in URLs are rejected.
  • DNS answers are checked for restricted IPv4/IPv6 ranges at each redirect hop.
  • The request is pinned to an inspected address while retaining the hostname for TLS.
  • Redirect count, request time, and streamed bytes are bounded.
  • Basic magic-byte checks reject unknown content instead of trusting filename extensions.
  • Temporary file permissions are restrictive, and temporary content is removed after validation.

Important gaps

There is no authentication, account isolation, rate limit, queue isolation, malware scanner, archive extraction guard, document sandbox, private object storage, production egress firewall, or external security review. ZIP files are recognized but not extracted or processed. The API must remain on a trusted local development network.

Report a vulnerability

Please use GitHub’s private vulnerability reporting for this repository. Do not include active exploit details in public issues. See repository security and SECURITY.md.
