Not a detour.

The extension source adds a “Send to ARBRIDGE” context-menu action for regular links and a compact side panel for public HTTPS URLs.

Development installation

  1. Install dependencies from the repository root with npm install.
  2. Build the Chrome extension with npm run build --workspace @arbridge/extension.
  3. Load apps/extension/.output/chrome-mv3 using Chrome’s extension manager and Developer mode.
  4. Start the API locally with npm run dev:api, then right-click a public link.

This is an unpacked development build, not a Chrome Web Store release. The local server URL is configured for development. The extension requires Telegram pairing and a connected Telegram account before it sends a file. No Chrome Web Store listing has been published.

What the extension does not do

It does not bypass protected pages, transfer browser cookies, upload local Downloads, extract ZIP archives, or provide AI processing. This unpacked build targets a local development API, not a public service or Chrome Web Store release.
