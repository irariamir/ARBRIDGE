How it works

A link travels.
You stay in control.

The prototype sends a link to a local ARBRIDGE API. The server fetches public HTTPS files directly from their source; it does not require a local browser download.

1. Choose a public file URL

On a normal webpage, right-click a link and choose “Send to ARBRIDGE”. Chrome passes the target URL and limited page metadata. The extension cannot add menu items to protected internal pages such as chrome://downloads.

2. The API asks a bounded downloader to fetch it

The downloader restricts requests to HTTPS on the standard port, validates DNS and every redirect destination, pins the connection to a checked public address, and enforces size, timeout, and redirect limits. It checks file signatures rather than trusting a filename.

3. Review a temporary status

The API validates the downloaded file and, if the account subscription is active, sends the original file to the paired Telegram private chat. Job status is temporary; restarting the API clears the record. There is no durable document library.

4. Pair the bot and activate a plan

Start the configured Telegram bot, send it the extension’s short-lived /connect code, then enter the confirmation code the bot sends back. Choose a plan in the bot. Example prices are not a live offer; payment requests remain disabled until an operator configures manual review. An authorized reviewer must approve a receipt before transfers are enabled.

If a URL needs your browser login, cookies, or institutional access, the remote downloader may be unable to access it. Do not submit confidential URLs to an untrusted server.
