Product scope

Useful by design.
Honest about status.

ARBRIDGE is building toward a shared browser and Telegram document workspace. The current repository contains an early public-link capture prototype—not a complete document manager.

Available in the prototype

  • Chrome Manifest V3 context menu for regular webpage links.
  • A side panel to submit a public HTTPS URL and review temporary request status.
  • A Fastify endpoint and bounded downloader that validates DNS answers and redirects, restricts network addresses, enforces byte and time limits, and checks basic file signatures.
  • A grammY bot for two-step account pairing, plan examples, manual receipt intake, private reviewer approvals, status, and recent delivered files.
  • Validated public-source files can be delivered with Telegram sendDocument after a connected user has an active subscription.
  • A Basic-auth admin page and numeric Telegram reviewer allowlist for manual receipt decisions.

Planned, not yet available

  • Persistent library, cross-device accounts, and deletion synchronization. Pairing currently works but its state is volatile.
  • Incoming Telegram document ingestion and persistent document storage.
  • PDF/DOCX parsing, OCR, summaries, tagging, embeddings, and AI search.
  • Durable queues, private object storage, rate limits, malware scanning, and production-grade worker isolation.
The API keeps sessions, plans, receipts, and jobs in memory. “Complete” means Telegram accepted the document message; it does not mean a permanent library save or AI processing happened.
