From a link to a place you can find it.

ARBRIDGE aims to connect a Chrome extension and a Telegram bot through a shared document workspace. The initial code focuses on one careful step: asking a trusted server to fetch a publicly accessible file, without making you download it locally first.

01 / CAPTURE

Send a file link

A Chrome context-menu prototype submits a public HTTPS link to a locally running API. Protected browser pages are not supported.

02 / CHECK

Bound the download

The prototype checks DNS destinations and redirects, limits bytes and time, and recognizes a small set of file signatures.

03 / CONNECT

Keep the next steps honest

Two-step pairing, Telegram file delivery is prototyped. Durable storage, document intelligence, and search remain future work.
