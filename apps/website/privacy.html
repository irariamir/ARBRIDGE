This notice describes the current ARBRIDGE development prototype. It is not a substitute for a reviewed privacy policy for any future hosted product.

What the prototype receives

The extension can send a URL and an optional title to the API configured in its source. The API resolves the host and requests the public HTTPS file. Temporary job metadata includes a random job ID, source hostname, title, timestamp, status, byte count, file type, and possibly a short error. Job records are kept in process memory and are lost when the server restarts.

Temporary file handling

The downloader writes files to a restricted temporary directory, checks the file signature, sends the file to the paired Telegram chat, then removes the temporary file after delivery or failure. Job metadata is volatile; there is no persistent document library. Payment-proof messages are copied to the operator-configured review group. A production log and retention review has not been completed.

Third parties and Telegram

When configured, the API sends validated documents to the paired Telegram private chat and forwards payment-proof messages to the operator-selected private review group. Telegram processes those messages under its own terms. No AI provider is connected.

Your choices

Do not use this prototype with confidential documents or URLs containing secrets, and do not expose its API/admin panel publicly. Pairing/session/job/receipt/subscription records are volatile. There is no account export, durable deletion, or persistent file library.

Contact

For the ARIAMIR project site, visit ariamir.ct.ws. A product-specific privacy contact and production policy must be established before public launch.
