Privacy notice

ARBRIDGE is a local testing prototype. The extension sends a public HTTPS URL and optional page title to the configured API. The API downloads the file, validates its network destination, size, and file signature, sends it to the paired Telegram private chat, and removes its temporary copy.

Pairing state, browser sessions, and transfer metadata are stored in process memory and are cleared when the API restarts. Telegram processes delivered files under its own terms and retention settings. Browser cookies are not forwarded. Login-protected sources are not supported.

Do not submit confidential URLs, private documents, or links containing access tokens. Keep the API bound to localhost while testing. No payment, receipt, or reviewer-group data is collected by this version.
