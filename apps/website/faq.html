Questions, clearly answered

send a link.

These answers describe the current prototype, not future roadmap promises.

Does ARBRIDGE send a file directly to Telegram?

The prototype can send a validated public-link download to a paired private Telegram chat after a manual Telegram pairing. This integration was not end-to-end tested with live credentials.

Do I need to download a file locally first?

No for public links: the server fetches the URL directly. It does not support Chrome’s protected downloads page, local file uploads, or authenticated browser sessions.

Will a link behind a sign-in work?

Usually not. The API does not use your browser cookies or institutional login. It only requests publicly accessible HTTPS URLs and does not bypass access controls.

Which files are recognized?

The downloader currently recognizes PDF, ZIP signatures, PNG, JPEG, GIF, WebP, and plain text. Recognition is not the same as document extraction or safe archive processing.

Are my captures saved permanently?

No. The API retains temporary status records only and removes its temporary file after Telegram delivery or failure. Telegram retains the message according to its own policies.

Does ARBRIDGE include AI summaries or search?

Not yet. No AI provider, embeddings, semantic search, or question-answering service is connected.
