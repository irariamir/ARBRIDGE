ARBRIDGE setup

Requirements: Node.js 22.13+, npm 10+, Chrome, and a Telegram bot created with BotFather.

Configure

Copy .env.example to .env. Set TELEGRAM_BOT_TOKEN, TELEGRAM_BOT_USERNAME, INTERNAL_API_SECRET, and the extension's EXTENSION_ORIGIN. Keep secrets private.

Run locally

npm ci
npm run dev:api
npm run dev:bot
npm run build --workspace @arbridge/extension

Run the API and bot in separate terminals. Load apps/extension/.output/chrome-mv3 from chrome://extensions with Developer mode enabled.

Test

Pair the extension using its one-time code, paste a public HTTPS file URL, or right-click a document link and select Send to ARBRIDGE. Supported types: PDF, ZIP, PNG, JPEG, GIF, WebP, and text. Default size limit: 20 MB.

This is a local testing prototype. Do not expose the API publicly or send confidential links. Transfer history is in memory and clears when the API restarts.
