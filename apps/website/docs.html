Documentation

Start with the
working parts.

The repository is an early engineering scaffold. Use it locally and read the limitations before connecting credentials or data.

Requirements

Node.js 22.13+ and npm 10+. Copy .env.example to .env only if needed, and keep actual credentials private.

Run the API

Copy .env.example to .env and set test-only secrets securely. In separate terminals run npm run dev:api and npm run dev:bot. The local API listens at 127.0.0.1:8787 by default. Read API routes and URL fetch security notes.

Build the Chrome extension

Run npm run build --workspace @arbridge/extension, then load apps/extension/.output/chrome-mv3 unpacked through Chrome’s extension manager.

Telegram bot and admin review

Configure the bot token, username, private review group, numeric reviewer allowlist, and shared internal secret only in a secure environment. The bot handles two-step pairing and manual sample-plan receipt review. Prices are illustrative ($4.99 monthly, $49.99 annual). The local /admin panel requires a non-default username and 24+ character password. See the operator guide.
